Why Computers Only Understand Two Numbers

Humans use language. Computers use electricity.

OFF = 0 — no electricity flowing
ON = 1 — electricity flowing
No in-between — a wire is never "half on"
  • Two-state signals are easier to separate from electrical noise.
  • Simple ON/OFF switching makes hardware cheaper and faster.
  • Complex apps are just huge combinations of these tiny decisions.

Everything a computer does starts from these two states, combined billions of times per second.

💡 Fun fact — A single transistor is just a tiny ON/OFF switch. Chain billions of them together and you get a CPU.

Why Binary Is Reliable

Real circuits use voltage to represent bits:

~5V — read as ON / 1
~0V — read as OFF / 0

Electrical noise rarely confuses a clean HIGH from a clean LOW — that's why binary survives in messy, real-world hardware.

Bits and Bytes

Bit — a single 0 or 1
Byte — a group of 8 bits

A byte can represent 256 different values (2⁸) — enough for one letter, number, or symbol.

  • File sizes are counted in bytes, KB, MB, GB, and TB.
  • Network speed is often shown in bits per second (bps).

Unicode: Why Emojis Exist

ASCII only covers 128 English-focused characters. Unicode extends this to over a million characters — covering every language and emoji.

Computers still store every one of these as binary — Unicode just agreed on a bigger shared numbering system.

  • UTF-8 is the most common Unicode encoding on the web.
  • Same character, different languages, one universal standard.
ASCII — 128 characters, 1 byte each
Unicode — 1M+ characters, up to 4 bytes each

Logic Gates: Binary Becomes Decisions

A logic gate is a tiny circuit that takes 0/1 inputs and produces a 0/1 output, based on a rule.

  • Inputs are usually called A and B; output is OUT or Q.
  • Gate behavior is summarized using a truth table.
  • Modern CPUs use billions of these logic decisions per second.

Combine enough of these tiny switches and you can build an entire computer.

NAND & NOR — The Universal Gates

NAND and NOR are universal gates — any other gate (and therefore any computer) can be built using only NANDs, or only NORs.

From Transistor to CPU

Millions → Billionsof transistors, each a tiny switch
Logic GatesAND, OR, NOT, XOR, NAND, NOR built from transistors
Adders & the ALUthe Arithmetic Logic Unit does all the math and logic
CPUcombined with control circuits, this becomes the processor

A modern CPU has over 20 billion transistors, flipping billions of times per second.

  • Transistor layer: physical ON/OFF switching.
  • Gate layer: logic decisions from transistor networks.
  • System layer: CPU coordinates memory, I/O, and timing.

How a Calculator Works

Buttons  →  Binary  →  Logic Gates  →  CPU  →  Answer  →  Screen

Pressing "5 + 3 =" converts each digit to binary, runs it through adders inside the CPU, and converts the binary result back into digits you can read.

5 in binary: 0101
3 in binary: 0011
  • Input stage: keypad sends digital signals to the controller.
  • Compute stage: ALU performs binary arithmetic operations.
  • Output stage: result is translated back to decimal for display.

Adders inside the CPU add 0101 + 0011 = 1000 (8) — then the screen converts it back to the digit "8".

Fun Facts

  • A modern CPU has over 20 billion transistors
  • Every transistor behaves like a tiny switch
  • Billions of switches change state billions of times per second
  • Your smartphone performs billions of calculations every second
  • The first electronic computer, ENIAC (1945), weighed 30 tons and had no transistors at all — just vacuum tubes
  • Binary was chosen because two-state electrical signals are far more reliable than ten-state ones
