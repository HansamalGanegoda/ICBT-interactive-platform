The Path of a Packet (Simple View)

Data is broken into small packets so it can travel efficiently through different links and devices.

1. CreateYour app creates data (text, image, or request).
2. AddressPacket gets source and destination IP details.
3. RouteRouters forward packets hop-by-hop to destination.

At the destination, packets are checked, ordered, and merged back into the original data.

What Is a Network, Really?

Devices — phones, PCs, servers
Links — cable, fiber, Wi-Fi
Rules — protocols like TCP/IP
Purpose — share data and services

A network is simply two or more devices connected so they can communicate and share resources.

Without shared rules and addressing, packets would not reach the right destination.

The Send → Route → Receive Cycle

SEND  →  ROUTE  →  RECEIVE  ↔  RESPOND

Example: You open a website request (send) → routers forward packets (route) → web server answers (receive) → page returns to your browser (respond).

Basics 1

Network Types: PAN, LAN, WAN

  • PAN — personal area network (Bluetooth earbuds, smartwatch)
  • LAN — local area network (home, lab, office)
  • WAN — wide area network (connects LANs across cities/countries)
  • The internet is the biggest WAN.
Basics 2

Network Topologies (Simple)

  • Star topology: most common in homes/schools (centered around switch/router).
  • Bus topology: older design using one main shared cable.
  • Mesh topology: many paths, higher reliability.
  • Good topology improves speed, maintenance, and fault tolerance.
Basics 3

Wired vs Wireless Connections

  • Ethernet (wired): stable, low latency, high reliability.
  • Wi-Fi (wireless): convenient and mobile.
  • Walls, distance, and interference affect wireless quality.
  • Best choice depends on use case (gaming, office, streaming, class lab).
Basics 4

IP Address: Device Identity

  • Every device needs an address to send and receive packets.
  • IPv4 example: 192.168.1.10
  • Private IP: used inside local network.
  • Public IP: visible to the internet through ISP/router.
  • IP works like a delivery address for end-to-end communication.
Basics 5

MAC Address: Hardware Identity

  • MAC address is a unique hardware ID of a network interface (NIC).
  • Example format: 00:1A:2B:3C:4D:5E (hexadecimal pairs).
  • MAC is mainly used inside a local network (LAN).
  • Switches forward frames using MAC address tables.
  • Simple memory tip: IP = where to go, MAC = which device here.
Basics 6

DNS: From Name to IP

  • You type a domain name (for example, example.com).
  • DNS server translates that name into an IP address.
  • Your browser then connects to the destination IP.
  • Without DNS, users would need to remember numeric IPs.
